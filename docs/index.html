  1. Download NEXUS_LAB_Setup.exe or NEXUS_LAB_Portable.exe from this page.
  2. For Setup: run the installer, choose a folder, finish — launch from Desktop or Start Menu.
  3. For Portable: double-click the EXE anywhere; no installation step.
  4. Press ` or F1 for the control panel. Use 1/2/3 to switch sandbox modes.
