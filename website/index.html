NEXUS LAB

Professional offline sandbox control panel for owned Windows test environments. Installer and portable builds — no third-party injection, no memory tampering, no anti-cheat interference.

Download Setup Download Portable GitHub Releases

SETUP.EXE

Full installer with Start Menu and desktop shortcuts. Recommended for most users.

PORTABLE.EXE

Single-file portable build. Run from USB or any folder — no install required.

SANDBOX ONLY

Platform testing, Aim Trainer, and ESP Visualizer run exclusively inside NEXUS LAB.

INSTALL & LAUNCH

  1. Download NEXUS_LAB_Setup.exe or NEXUS_LAB_Portable.exe from this page or GitHub Releases.
  2. For Setup: run the installer, choose a folder, finish — launch from Desktop or Start Menu.
  3. For Portable: double-click the EXE anywhere; no installation step.
  4. Press ` or F1 to open the control panel. Use 1/2/3 to switch sandbox modes.
